# morning-slides

Слайды утреннего отчёта из его markdown. Детерминированно: модель пишет `.md` по
шаблону навыка `morning`, рендерер превращает его в один `.html` без внешних
библиотек — титул с KPI-карточками, слайд на каждый `## Раздел`, последний —
«Нужны решения». Стрелки/прокрутка, печать по слайду на страницу.

```sh
python3 render.py GROUND/PULSE/morning/2026-09-11.md        # → рядом .html
python3 render.py report.md -o out.html
python3 -m unittest discover -s test                        # 8 юнит-тестов рендера
node test/e2e.mjs                                           # E2E кликов: Chromium из ../mts-link-sync, JS вкл/выкл, 700px, пустые данные
```

Разметка, которую понимает: `# Утро …`, строка `KPI: a N · b M · …`, `## `, `### `,
таблицы GFM, списки `- `, `**жирная строка**` (заголовок группы KR),
`[НЕТ ДАННЫХ: …]` (плашка), строка `Прочее: …` (подвал). Внутри ячеек: `PO-123` и
`GDSLV-123` подсвечиваются как id, `· −N д` — красный бейдж, ячейка `HIGH` — красная.

Код выхода 1 — нет `# ` или `## `: отчёт не по шаблону, чинить отчёт, не рендерер.

## Слайд ретро

Если рядом с `.md` лежит `<имя>.retro.json` (пишет навык, схема в SKILL.md, шаг 4),
слайд «Ретро» — два виджета: **Activity** (созвоны за вчера) и **Tasks** (сделанное:
задачи Backlog.md с id или результаты без id). Таблицы из markdown на слайде нет.
Клик по строке открывает справа заметку — блочный редактор (порт `BlockEditor`
poh-okr-plugin на vanilla JS), всегда в режиме правки, без переключателей:
первая строка — название (оно же подпись строки виджета, любой длины), «/» в пустой
строке — меню блоков (Текст, Заголовок 1–3, списки, Пункт с галочкой, Цитата,
Разделитель), сокращения `- `, `[] `, `# `, `---`, Enter продолжает список, Backspace
в пустом пункте выходит из него. «Источники» — обычный раздел `## Источники` внутри
заметки, обязателен. Красная вкладка «Описать ретро» слева видна только на этом
слайде и открывает заметку ретро с заготовкой из четырёх разделов.

В шапке панели — чек, дата («Вчера»/«Сегодня»/ДД.ММ из `done_at`/`due`, время из
`start`–`end`) и флаг приоритета, как в TaskSheet okr-плагина.

Правки сохраняются в localStorage браузера по дате и заметке. **Редактор требует
JavaScript.** Без него заметка показывается статичным рендером markdown и внизу
экрана висит баннер «Скрипты отключены»; панели открываются и без JS — скрытые
`radio`/`checkbox` + `label`. Просмотрщик файлов в Claude скрипты не исполняет —
для правки открывать файл в Safari или Chrome.
Строка без `## Источники` или без названия — код выхода 1. Пример —
`test/sample.retro.json`.

## Слайд «Сегодня»

Если рядом лежит `<имя>.today.json` (схема в SKILL.md, шаг 4), слайд «Сегодня» — те же
виджеты с заметками: **Задачи** (чек с цветом приоритета, id, KR или срок) и
**Договорённости**. Две вкладки слева: зелёная «План на сегодня» (заметка с
разделами Задачи / Созвоны / Договорённости / Риски) и синяя «Календарь» — панель
со списком созвонов дня (время, тема, участники, повестка; только чтение). На самом
слайде созвонов нет. Тема везде тёмная, как у панелей. При смене слайда открытые
панели закрываются (с JS).

Без JavaScript текст заметок всё равно правится — статичный рендер `contenteditable`,
но без сохранения, меню «/» и блоков; с JavaScript монтируется полный редактор.

## Слайды «Риски» и «Команды»

`<имя>.risks.json` — таблица OKR · Название · Последствия (клик — заметка с описанием,
последствиями, владельцем, статусом, источниками), слева янтарная вкладка
«Актуализация рисков» (Новые / Изменились / Сняты / Нужно решение).

`<имя>.teams.json` — раздел «Статус по командам» разворачивается в слайд на команду:
История · Что сделано · Что осталось · Следующий шаг (дата · что проверять · у кого),
клик — заметка со всей историей за спринт (сделано, осталось, блокаторы, следующий
шаг, пульс, источники). Слева «Комментарий» (по умолчанию — сводка по каждой истории:
что уже сделано / что осталось / какие есть блокаторы / какой следующий шаг) и
«Договорённости» — реестр-чеклист «что · от кого · когда · кому».

На «Сегодня» появился третий виджет «Ключевые встречи»: созвоны с `key: true`
(не ритуалы) с повесткой; полный календарь — в панели.

## Узкий экран (панель dsh, телефон)

При ширине окна ≤ 760px тот же файл перестраивается в приложение: лента карточек
вместо слайдов (без scroll-snap), сверху прилипшая навигация чипами по разделам
(дата · Ретро · Сегодня · Риски · команды · Решения), титул сжат до шапки с KPI-чипами,
виджеты в один столбец, вертикальные вкладки становятся кнопками-пилюлями под
заголовком раздела, таблицы (истории, риски, markdown) — карточками «подпись:
значение», строки не ниже 48px с переносом заголовка, панели-заметки на весь экран
с прилипшей шапкой, `100dvh`. Взаимодействие — мышь и прокрутка, тач не обязателен.
Порядок разделов тот же, что на десктопе.

E2E добавляет вьюпорты 420×900 (панель dsh, JS: редактор и меню «/» в узком экране)
и 390×844 (без JS): нет горизонтальной прокрутки, навигация ведёт к разделу,
кнопки горизонтальные, строки ≥ 44px, панель во всю ширину, карточки с подписями.
